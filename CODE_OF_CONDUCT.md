# Code of conduct

## Our standard

We want this project to be a respectful place for everyone, whatever their background, experience or identity.

- Be kind and direct. Critique code and ideas, not people.
- Assume good intent, and ask before assuming.
- Help newcomers find their way.

Not acceptable: harassment, insults, discriminatory jokes or language, sexual content, threats, publishing someone's private information, and sustained disruption.

## Scope

This applies in the repository, the contributors portal, and any community space for the project.

## Reporting

Email **operations@nextrium.org**. Reports are read by the project maintainers and handled confidentially.

## Enforcement

Depending on what happened, maintainers may:

1. Send a private warning.
2. Remove content and restrict participation for a period.
3. Ban the person from the project.

Maintainers who don't follow this code may face the same steps.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
