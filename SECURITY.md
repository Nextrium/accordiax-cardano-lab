# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. This includes any way to move escrowed funds without the conditions the contract is meant to enforce.

Don't open a public issue or pull request about a vulnerability. Test only on Preprod, with your own test wallets.

## What to expect

- We confirm receipt within **3 working days**.
- We share our assessment and planned fix within **10 working days**.
- We credit you when the fix ships, unless you'd rather we didn't.

## Supported versions

Only the latest contract on `main` is supported. This contract is a Preprod prototype and is not deployed on mainnet.
